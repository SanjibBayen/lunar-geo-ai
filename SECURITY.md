# Security Policy

## Project Status

Lunar is currently in active development and testing.

As the project is experimental, vulnerabilities, bugs, performance issues, and incomplete functionality may exist.

---

## Supported Versions

| Version             | Supported |
| ------------------- | --------- |
| Current Main Branch | ✅         |
| Previous Versions   | ❌         |

---

## Reporting a Vulnerability

If you discover a security issue, please report it privately.

### Contact

Email: [sanjibayen04@gmail.com](mailto:sanjibayen04@gmail.com)

### Include

* Description of the issue
* Steps to reproduce
* Impact assessment
* Screenshots or logs (if available)

---

## Response Process

1. Acknowledge report
2. Investigate issue
3. Validate vulnerability
4. Develop fix
5. Release update

Response times may vary depending on project activity and severity.

---

## Responsible Disclosure

Please do not publicly disclose vulnerabilities before they have been reviewed and addressed.

We appreciate responsible reporting that helps improve the reliability and security of the project.

---

## Disclaimer

This project is experimental research software and should not be used in safety-critical or mission-critical environments without independent verification and validation.
